# 9minecraft OptiFork - The Next Generation of OptiFine

⭐ New & recommended: Try OptiFine HD 9minecraft - an all-in-one pack that combines high-FPS performance, shaders, and OptiFine-style features (zoom, fullbright, connected textures, CEM) in a single easy installer. 9minecraft OptiFork is the next generation of OptiFine - a from-scratch rebuild for the modern Fabric and NeoForge loaders that finally brings OptiFine's signature performance tweaks, connected textures, and Dynamic Lights to modern Minecraft.

## What this build is

Built and maintained in-house by 9Minecraft Studios.
